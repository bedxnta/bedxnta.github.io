How MarkPlane works: write, preview, take it with you.

MarkPlane turns your Markdown into a readable preview right in your browser. Your writing stays on your device until you choose to copy or download it.

A simple writing flow

Each part of the editor runs locally, using standard browser features—no account or document service in the middle.

01

Write in Markdown

Type in the editor or use the toolbar to add common Markdown syntax such as headings, emphasis, lists, links, and code.

Text area → Markdown source
02

Preview as you go

MarkPlane updates the preview as you type. It handles familiar Markdown blocks and escapes raw HTML rather than inserting it into the page.

Markdown text → safe HTML preview
03

Save on this device

The current document name and text are autosaved to this browser’s local storage. Use the same browser profile to reopen your draft later.

Document → browser localStorage
04

Export when you’re ready

Copy the Markdown to your clipboard or download a plain-text .md file to use in another editor or share yourself.

Markdown text → clipboard or .md file

What the preview supports

Headings, paragraphs, line breaks, bold and italic emphasis, strikethrough, ordered and unordered lists, task lists, blockquotes, horizontal rules, links, inline code, and fenced code blocks.

For safety, raw HTML is displayed as text. Links in the preview are limited to HTTP, HTTPS, mailto, or relative URLs.

Frequently asked questions

?Does MarkPlane upload my notes?

No. Editing, previewing, saving, copying, and downloading happen locally in your browser. The Google Fonts stylesheet is an optional external resource used for the app’s typography.

?Where does autosave go?

The current document is stored in this browser’s local storage on this device. Clearing site data or using a different browser profile removes access to that local draft, so download important work.

?Can I use my Markdown elsewhere?

Yes. Copy the source or download it as a standard .md text file.

?What shortcuts are available?

Use Ctrl/⌘ + B for bold, Ctrl/⌘ + I for italic, and Ctrl/⌘ + S to save immediately in the browser.
